# Memo Rack

大枠(スペース)→カテゴリ→メモの階層で整理できる、iPhone向けのシングルファイルWebメモアプリです。
フレームワーク・ビルド不要。`index.html` 1枚で動作します。

## 特徴

- **大枠 → カテゴリ → メモ**の3階層で整理(例: 日常 / 勉強 / 音楽)
- カテゴリ・大枠は自由に追加・削除・色分け可能
- 検索、ピン留め
- **背景テーマ**: ライト5色・ダーク5色
- **アクセントカラー**: レッド / ブルー / イエロー(3パターン)
- **セーブ / ロード**: 現在の状態を名前付きで保存し、後から呼び出し・切り替え可能
- データは端末内(localStorage)に保存。サーバー・アカウント登録不要
- iOSの「ホーム画面に追加」でアプリのように全画面起動(PWA対応)

## 使い方

### そのまま開く
`index.html` をブラウザで開くだけで動作します。

### GitHub Pagesで公開する
1. このリポジトリの Settings → Pages で Source を `main` ブランチ / `/ (root)` に設定
2. 発行されたURLにiPhoneのSafariでアクセス
3. 共有ボタン →「ホーム画面に追加」でアイコンが追加され、アプリのように使えます


## データについて

すべてのデータはブラウザのlocalStorageに保存されます(サーバー送信なし)。
機種変更やストレージクリア時に備えて、アプリ内の「セーブ/ロード」機能でこまめにバックアップを取ることをおすすめします。
